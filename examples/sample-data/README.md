# 合成示例数据 / Synthetic sample data

本目录中的每一条记录均为公开演示而生成的虚构数据，没有复制正式系统中的用户、订单或库存。

数据规模：17 个账号（5 个商家、12 个学生）、40 道菜、180 笔订单、344 条订单明细。订单覆盖 45 天的午餐和晚餐时段，包含已下单、备餐中、已完成、已取消四种状态；菜品覆盖不同价格、热销与滞销、正常库存、低库存、售罄及下架场景。

`users.csv` 仅包含演示密码对应的合成 PBKDF2 盐和哈希。根目录 README 中公开的学生、商家账号均可用于本地 H2 演示。

使用以下命令可按固定规则重新生成完全相同的四份 CSV：

```powershell
python .\scripts\generate-sample-data.py
```

请勿使用真实安装导出的文件替换这些公开样例。
